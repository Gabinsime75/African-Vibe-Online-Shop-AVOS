	Terraform plan exit code: 1
	
Solution:
	Terraform exit code 1 means the plan failed because the cached AWS CLI SSO session for avos-admin is expired or invalid.
	Signing into the AWS web portal does not automatically refresh the AWS CLI session.

		Run:
			export AWS_PROFILE="avos-admin"
			export AWS_REGION="us-east-2"
			export AWS_DEFAULT_REGION="us-east-2"

			aws sso login --profile "$AWS_PROFILE"
			
		Complete the browser authorization, then verify the CLI credentials:
			aws sts get-caller-identity --profile "$AWS_PROFILE"
			
		You should receive your account ID and an assumed-role ARN. 
		Then rerun:
			terraform -chdir=terraform/governance plan \
			  -out=governance-kms.tfplan \
			  -detailed-exitcode

			PLAN_EXIT_CODE=$?
			echo "Terraform plan exit code: $PLAN_EXIT_CODE"
		
		The exit codes mean:
			| Code | Meaning                              |
			| ---: | ------------------------------------ |
			|  `0` | Plan succeeded; no changes           |
			|  `1` | Error occurred                       |
			|  `2` | Plan succeeded; changes are proposed |
		
If aws sso login still produces InvalidGrantException, reset the cached CLI session:
		aws sso logout
		aws sso login --profile avos-admin
		aws sts get-caller-identity --profile avos-admin	

If authentication works but Terraform still fails, refresh the backend connection:	
	terraform -chdir=terraform/governance init \
	  -reconfigure \
	  -backend-config=backend.hcl
	Then rerun the plan. This is an authentication-session problem, not an error in the governance or KMS Terraform code.
